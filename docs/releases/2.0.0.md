# ADHD & 47 Tabs v2.0.0

Version 2 rebuilds the project as a tested response-design system for reducing cognitive load across research, school, work, technical tasks, and everyday logistics.

## Breaking package rename

The canonical package is now `adhd-and-47-tabs.zip`, containing one top-level folder named `adhd-and-47-tabs`.

Remove or disable the previous `i-have-adhd-and-47-tabs` installation before installing v2. Keeping both enabled can cause duplicate or conflicting instructions.

## Highlights

- Adds answer, action, artifact, and project-update response contracts.
- Preserves necessary depth, citations, uncertainty, warmth, and requested formatting.
- Stops appending artificial next steps to complete answers and finished deliverables.
- Adds progressive disclosure, ranked choices, definitions of done, sequential troubleshooting, and evidence-based progress reporting.
- Adds behavior for complex questions, emotional support, creative work, deep explanations, long requested lists, and irreversible actions.
- Adds 14 portable evaluation scenarios and a dependency-free JSONL response scorer.
- Strengthens metadata, package, version, attribution, identity, and stale-reference validation.
- Standardizes every install and release path on `zgbrenner/adhd-and-47-tabs`.

## Install

Download `adhd-and-47-tabs.zip` from the release assets and upload or install it through a supported Agent Skills interface.

The skill contains no executable scripts, credentials, network calls, or external dependencies.

## Verify

Download `SHA256SUMS` beside the ZIP, then run:

```bash
sha256sum -c SHA256SUMS
```

## Evaluate behavior

After collecting model responses in JSONL format:

```bash
python3 scripts/score_responses.py --responses responses.jsonl
```

Structural scoring does not replace human review for factual accuracy, sourcing, tone, and completeness.
