# ADHD & 47 Tabs v3.0.0

Version 3 turns the project from a strong answer-formatting skill into an adaptive interaction system for starting, continuing, resuming, deciding, recovering, and finishing.

## Highlights

### Interruption recovery

Use a compact breadcrumb:

> **You are here:** goal → verified state → next action.

The skill restores the active thread without replaying the entire history.

### Memory offloading

Names, dates, constraints, paths, and prior decisions are reused at the point of action. The user is asked only for information that is genuinely missing.

### Small working set

Complex work is organized into one Active item, up to two Ready items, relevant blockers, and normally hidden Parked work.

### Repeated-failure recovery

After two clear unsuccessful attempts, the skill stops generating nearby guesses and switches to:

1. Known evidence.
2. The likely wrong assumption.
3. One discriminating diagnostic.

### Finish protection

Definitions of done remain observable, optional polish is parked, and completion is claimed only after verification.

### User controls

`one thing`, `map it`, `resume`, `park that`, `more detail`, `less detail`, `why this`, and stop mode now provide compact conversational control.

## Evaluation and packaging

- 47 provider-neutral cases across 15 categories.
- Nine multi-turn cases for interruption, memory reuse, state advancement, absent-memory safeguards, and recovery.
- Text, JSON, and Markdown reports.
- Richer deterministic assertions and category summaries.
- Fixed timestamps, permissions, entry order, atomic ZIP generation, byte-level source verification, and SHA-256 checking.
- No hosted CI, API keys, executable skill code, telemetry, or third-party dependencies.

## Upgrade

The slug remains `adhd-and-47-tabs`. Replace the v2 ZIP or folder, then restart or reload the host if it caches skills.

Users of the retired v1 slug `i-have-adhd-and-47-tabs` should remove that copy before installing v3.
