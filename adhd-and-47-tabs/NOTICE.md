# Attribution and adaptation notice

## Upstream project

This project is adapted from [`ayghri/i-have-adhd`](https://github.com/ayghri/i-have-adhd) by **Ayoub Ghriss**.

The upstream project established the central response-design idea: reduce friction by surfacing the useful action, bounding multi-step work, preserving state, suppressing tangents, making progress visible, and removing empty preambles and closers.

## This adaptation

**ADHD & 47 Tabs** was adapted by **Zachary Brenner** for cross-platform use across research, school, writing, planning, administrative work, decisions, everyday logistics, and technical work.

Version 3 materially extends the adaptation by:

1. Preserving four base response contracts while adding six adaptive modifiers.
2. Adding interruption recovery through a compact **You are here:** breadcrumb.
3. Reusing reliable conversation details as external memory rather than asking for redundant re-entry.
4. Separating Active, Ready, Blocked, and Parked work to protect a small visible working set.
5. Adding a repeated-failure circuit breaker and finish-line scope protection.
6. Adding concise user controls for scope, depth, orientation, parking, rationale, and stop mode.
7. Expanding the provider-neutral evaluation suite to single-turn and multi-turn cases.
8. Strengthening deterministic local validation, reporting, packaging, and research attribution.
9. Supporting Claude, ChatGPT Skills, Codex, GitHub Copilot, compatible Agent Skills hosts, and a Custom GPT fallback.
