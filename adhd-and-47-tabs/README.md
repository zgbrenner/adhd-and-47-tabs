# ADHD & 47 Tabs

A cross-platform Agent Skill that makes responses easier to scan, start, and finish without stripping away necessary depth.

The skill follows the Agent Skills open specification and is designed for Claude, ChatGPT Skills, Codex, GitHub Copilot, and compatible hosts. It contains no executable code, credentials, network calls, or external dependencies.

The complete project, installation instructions, evaluation suite, attribution, tests, canonical downloadable ZIP, checksum, and packaging scripts live at the repository root: https://github.com/zgbrenner/adhd-and-47-tabs
